# Host mapping
Session.Backend/Workspace/Model/Id/Attempted remain host-owned and immutable within a library session binding.
The library request receipt is local durable acceptance, not a SharpClaw start acknowledgement.
A library observation must be awaited before the adapter proceeds with dependent external effects.
The reference must confine actual SharpClaw child cleanup to a dedicated worker. Arbitrary plugins and late-ID transports require their own concrete proof; no implicit retry or session replacement.
